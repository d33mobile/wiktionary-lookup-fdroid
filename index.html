Wiktionary Lookup: F-Droid repo

An offline dictionary built from English Wiktionary. Results update on every keystroke; search by headword, by romanization (pinyin for Chinese) or by English words in the definitions. Chinese (about 190,000 entries) ships inside the APK; every other language English Wiktionary covers can be downloaded from the language menu and is kept on the device.

Add this repo to F-Droid

  1. Install the F-Droid client from f-droid.org if you don't have it yet.
  2. In F-Droid: Settings → Repositories → +, then scan the QR code or paste the URL below.
  3. Update repos, then install “Wiktionary Lookup”.
