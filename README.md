# Wiktionary Lookup: F-Droid repo

Personal F-Droid repository hosting Wiktionary Lookup, an offline
Chinese-English dictionary built from English Wiktionary data (via
kaikki.org, CC BY-SA 4.0).

## Add this repo on your phone

In the F-Droid client: **Settings > Repositories > +**, then scan the QR code
or paste the URL with fingerprint shown on the
[landing page](https://d33mobile.github.io/wiktionary-lookup-fdroid/).

## Repository contents

This branch is served by GitHub Pages from the repo root. The F-Droid index
and the APK live under `repo/`.
